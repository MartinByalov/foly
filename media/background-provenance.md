# Static homepage background

`background.webp` is a single 1280 × 720 frame extracted at 0.1 seconds from
the previously configured homepage background video, encoded as WebP at quality 90.
It preserves the former paused-frame composition. The browser now loads only
this local image; it does not fetch the source video.

Historical source:
`https://video.wixstatic.com/video/26357a_07594806ca564172be0267fa44f5ac9a/720p/mp4/file.mp4`
